# תהילים

אפליקציית PWA להקראת תהילים פסוק אחרי פסוק, עם הפסקה בין פסוקים שאורכה תלוי באורך הפסוק, קריאה ברצף פרקים וסימון פרקים שנקראו. עובדת גם בלי רשת אחרי הפתיחה הראשונה.

- הקראה: Web Speech API (קול עברי של המכשיר). באייפון: הגדרות, נגישות, תוכן מדובר, קולות, עברית.
- טקסט: תנ"ך עם ניקוד, [Sefaria](https://www.sefaria.org) (Public Domain, מקור: tanach.us).
- אתר: GitHub Pages מהענף `main`, מהתיקייה הראשית.
- התקנה באייפון: פתיחה ב-Safari, שיתוף, "הוסף למסך הבית", ומשם פתיחה רק דרך האייקון.

## בנייה מחדש

```bash
python3 src/build.py src/psalms_nikkud.json index.html --standalone
python3 src/make_icons.py .      # אייקונים, דורש playwright ו-Chrome
```

אחרי שינוי בקבצי האפליקציה כדאי להעלות את הגרסה ב-`sw.js` (`APP`), כדי שמכשירים קיימים יקבלו עדכון.
